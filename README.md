A runnable recreation of the uploaded 23.73-second, 720×1280 screen recording.

## Effects identified in the video

1. **The Chaser Track** — a raised circular track with an inset rotating runner.
2. **The Morphing Droplet** — a soft embossed shape that continuously changes its border radius.
3. **The Hydraulic Press Wave** — three embossed dots that pulse in a staggered vertical wave.
4. **The Accent Ping** — a small blue accent point with a repeating expanding ring.
5. **The Metallic Angle Dial** — a raised circular dial with a metallic angled surface and rotating accent.

The recording shows each effect on a pale blue-gray neumorphic card, with a dark code panel below it. The project recreates that presentation and includes all five loaders in one scrollable page.

## Source extraction note

The video shows portions of HTML/CSS source in small code panels. The readable effect names, selectors, dimensions, keyframe concepts, animation timings and visible values were transcribed where legible. Some tiny or obscured characters are not reliably readable in the recording; those portions are reconstructed to produce working animations. The displayed snippets are clean, representative CSS for each recreated effect, not a claim of byte-for-byte recovery of the creator's complete source.

## Run

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Scroll to see all five continuously animated loaders.
4. Use **Copy CSS** in any card to copy that effect's snippet.

No npm, build process, external assets or network connection is required.

## Files

- `index.html` — five loader cards and source panels
- `style.css` — neumorphic layout and five animations
- `script.js` — source snippet injection and copy buttons
- `README.md` — instructions and source notes
